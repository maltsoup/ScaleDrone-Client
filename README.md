## 🛠 Usage

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Enter a **Channel ID** (you can create one from your Scaledrone account).
4. Start chatting with anyone else connected to the same channel.

---

## ⚙️ Settings

- **Dark Mode**: Top-right toggle (☾/☀ icons).  
- **Settings Panel** (⚙️ icon):  
  - Change name, color, and channel.  
  - Enable/disable timestamps.  
  - Choose 12h or 24h time format.  
  - Reset name & color.
